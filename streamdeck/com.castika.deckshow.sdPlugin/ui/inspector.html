How Castika DeckShow works

Settings

These settings apply to every DeckShow Button.

Peak hold leaves a thin line at the highest point a meter reaches, and it slides down one button per second until the meter catches it again. It belongs to the Stripe style, so it is only offered there.

Start / Stop

  • Stop on use: with this on, typing or moving the mouse ends the show, like a screen saver. Off leaves it running until a button is pressed.
  • Press any DeckShow Button quickly to start the show. Press it again to stop.
  • The show also starts by itself after the Start After idle time.
  • Hold any DeckShow Button for 1.5 seconds to turn the show off for this session. This works even if Auto Restart is on and After stop is set to Resume on idle. A quick press turns it back on.

Where the show runs

  • If the current page has DeckShow Buttons, the show runs only on those buttons and stays on that page.
  • If the page does not have any DeckShow Buttons, the show switches to the built-in Castika DeckShow Profile for that device. When the show stops, it goes back to the previous profile.
  • Buttons stacked in one column work as one meter. The bottom button fills first, then the one above it.

Several Stream Decks

Every connected Stream Deck runs its own show at the same time. Each one decides for itself: its own buttons if it has any, the built-in profile if not.

This deck applies to the Stream Deck the button is on. Set it to Off for any deck you want to keep out. Every deck is in the show by default.

The first time the plugin starts, the Stream Deck app asks you to install the built-in profile. That happens once per kind of device (for example once for a Mini, once for an XL), not once per device. The buttons flash briefly while this happens.

When your display turns off

The Stream Deck app turns the device off while your display is asleep, so the show is not visible then. When the display comes back on, the show continues where it left off. Display sleep is set in your operating system, not here.

After stop

  • Resume on idle: The show starts again at the next idle time.
  • Stay off: The show stays off until the next boot or wake (if Auto Restart is on) or until you set This deck back to On.
